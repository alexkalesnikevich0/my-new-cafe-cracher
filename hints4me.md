Основные команды

Команда Что делает
npm run dev Запускает сервер разработки
npm run build Собирает проект для продакшена
npm run start Запускает собранный проект
npm run lint Проверяет код на ошибки и стиль
npm run test Запускает тесты

---

Как войти в админку

1. Перейди по адресу: http://localhost:3000/admin
2. Введи пароль, который указан в переменной ADMIN_PASSWORD в .env.local

В админке ты можешь:

· Просматривать все брони в таблице
· Подтверждать или отменять брони
· Фильтровать брони по дате и статусу
· Экспортировать все брони в CSV-файл

---

Как работают уведомления

1. Клиент заполняет форму бронирования и нажимает "Submit".
2. Сервер проверяет данные и доступность.
3. Если всё в порядке:
   · Бронь сохраняется в базу данных.
   · На почту администратора (MY_EMAIL) приходит уведомление о новой брони.
   · Гостю приходит письмо с деталями брони.
   · В Telegram приходит уведомление с информацией о брони.
4. После подтверждения или отмены брони администратору и гостю отправляются письма об изменении статуса.

Тесты

Для запуска тестов используй команду:

```bash
npm run test
```

Тесты проверяют:

· Валидацию данных (гости, дата, время, email)
· Проверку доступности (свободные слоты)

---

Деплой

Проект настроен для автоматического деплоя на Vercel.

1. Зарегистрируйся на Vercel.
2. Подключи репозиторий.
3. Добавь переменные окружения (те же, что в .env.local).
4. Нажми "Deploy".
