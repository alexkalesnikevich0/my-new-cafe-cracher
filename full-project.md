# КАРТА ПРОЕКТА: CAFE CRACHER

Этот файл поможет быстро разобраться, как устроен проект, где что лежит и за что отвечает.

---

## ОСНОВНЫЕ ФАЙЛЫ И ИХ ЗАДАЧИ

| ФАЙЛ                                   | ЧТО ДЕЛАЕТ                                                                                           |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `app/booking/actions/booking.js`       | Главный экшен. Принимает данные из формы, проверяет, сохраняет в БД, отправляет письма и в Телеграм. |
| `app/booking/actions/updateStatus.js`  | Обновляет статус брони (confirm / cancel). Отправляет письмо гостю.                                  |
| `features/booking/lib/validation.ts`   | Проверяет данные брони (гости, дата, время, email). Возвращает ошибку или null.                      |
| `features/booking/lib/availability.ts` | Проверяет, свободно ли время (есть ли уже бронь).                                                    |
| `features/booking/types.ts`            | Описывает типы данных (BookingStatus, CreateBookingInput, ActionResult).                             |
| `app/booking/components/menuForm.js`   | Форма бронирования (клиентская часть). Отправляет данные в `createBooking`.                          |
| `app/booking/V2/PaginationBooking.jsx` | Таблица броней в админке. Фильтры, пагинация, автообновление.                                        |
| `app/admin/admin-login/route.js`       | API для входа в админку (проверка пароля, создание куки).                                            |

## ОСНОВНЫЕ КОМАНДЫ

| КОМАНДА               | ЧТО ДЕЛАЕТ                                                 |
| --------------------- | ---------------------------------------------------------- |
| `npm run dev`         | Запускает сервер разработки (локально).                    |
| `npm run build`       | Собирает проект для продакшена (генерирует Prisma Client). |
| `npm run start`       | Запускает собранный проект.                                |
| `npm run lint`        | Проверяет код на ошибки и стиль (ESLint).                  |
| `npm run test`        | Запускает тесты (Vitest).                                  |
| `npx prisma db push`  | Применяет схему Prisma к базе данных (создаёт таблицы).    |
| `npx prisma generate` | Генерирует Prisma Client (нужно после изменений в схеме).  |

## ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (файл `.env.local`)

| ПЕРЕМЕННАЯ           | ЗАЧЕМ НУЖНА                                       |
| -------------------- | ------------------------------------------------- |
| `DATABASE_URL`       | Подключение к базе данных (Supabase).             |
| `ADMIN_PASSWORD`     | Пароль для входа в админку (`/admin`).            |
| `MY_EMAIL`           | Почта администратора (куда приходят уведомления). |
| `RESEND_KEY`         | API-ключ для отправки писем (Resend).             |
| `TELEGRAM_BOT_TOKEN` | Токен бота для уведомлений в Телеграм.            |
| `TELEGRAM_CHAT_ID`   | ID чата в Телеграм (куда приходят уведомления).   |

## КАК ДОБАВИТЬ НОВУЮ ФИЧУ (КРАТКИЙ ПЛАН)

1. Создай новый компонент в `src/app/booking/components/` или `src/components/`.
2. Напиши серверный экшен в `src/app/booking/actions/`.
3. Добавь типы в `src/features/booking/types.ts` (если нужны новые типы).
4. Напиши тесты в `src/features/booking/tests/`.
5. Закоммить и запушить.
